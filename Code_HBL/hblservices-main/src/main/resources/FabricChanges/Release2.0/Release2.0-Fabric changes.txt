TermNConditionsCode-Api
http://localhost:8304/ms-consent-api/api/v2.0.0/reference/termNConditionsCode
{
  "termConditionCode": "Thirdparty_Auth",
  "consentType": "GENERIC.INFO",
  "title": [
    "Thirdparty_Auth code"
  ],

  ]
