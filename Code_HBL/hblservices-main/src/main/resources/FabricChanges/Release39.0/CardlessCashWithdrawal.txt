The following server properties have been introduced in Fabric-

1. Authentication Validation Toggle
Server Property - CARDLESS_CASH_AUTH_VALIDATION_ENABLED

Purpose - This property controls whether authentication validation should be performed before processing the API request.

Supported Values
true - Authentication validation is enabled. The API validates the incoming X-Custom-Auth header before processing the request.         
false - Authentication validation is disabled. The API bypasses authentication validation and proceeds directly with business processing.

2. Authentication Configuration
Server Property - CARDLESS_CASH_AUTH_CONFIG

Purpose - This property stores the username and password used for validating incoming authentication requests.

The API reads the configured credentials from this server property and compares them against the credentials received in the `X-Custom-Auth` request header.

Configuration Format

=====json====
{"username":"admin","password":"secret123"}
